Privacy

Nothing to spill.

Brewlight doesn't know who you are, and it doesn't want to. Here's exactly what it does on your Mac and on the network.

Last updated 3 November 2026

  • No accountNothing to sign up for or sign in to.
  • No trackingNo analytics, crash reporting or ads of its own.
  • Password never keptIt goes straight to sudo and nowhere else.
  • Stays on your MacTags, notes and history never leave it.

What Brewlight connects to

Brewlight only goes online to do the job you opened it for. None of these requests include anything about you beyond what any web request carries: your IP address and a Brewlight/<version> user agent. The optional ones can be switched off under Settings → Privacy.

Homebrew's package catalog formulae.brew.sh

The list of every formula and app, so you can search it. Brewlight checks whether it has changed first and skips the download when it hasn't.

If you pick a download mirror or your own API address, these requests go there instead.

Install counts formulae.brew.sh/api/analytics

Homebrew's public, already-aggregated download totals, used for Discover and sorting by popularity. Brewlight reads them; it doesn't send any.

Turn off with “Fetch install statistics from formulae.brew.sh”.

Package icons github.com and package homepages

For packages that aren't installed, Brewlight tries the homepage's icon or the GitHub owner's avatar. Installed apps use the icon already on your Mac. Icons are cached so each is fetched once.

Turn off with “Fetch package icons from the web” to show letter tiles instead.

Homebrew's installer api.github.com

Only if Homebrew isn't installed yet: Brewlight looks up the latest official installer so it can offer to set Homebrew up for you.

Installing, upgrading and removing packages is done by Homebrew itself, which downloads from its own servers, GitHub and the developers of each app. Homebrew has its own anonymous analytics. Brewlight shows whether they are on and lets you switch them off, but never changes them unless you do.

What stays on your Mac

Everything Brewlight remembers is stored locally, in your user Library. It isn't synced or uploaded anywhere.

Your tags, favourites, notes, skipped versions and history~/Library/Application Support/Brewlight
The catalog, install counts and icons it has downloaded~/Library/Caches
Logs of the brew commands it ran~/Library/Logs/Brewlight

You can export, import or erase all of it from Settings → Advanced, and clear the caches from Settings → Privacy. Your settings are kept in the usual macOS preferences file, like any other app's.

If you turn on “Keep a copy in iCloud Drive” for Brewfiles, the Brewfile you export is copied to your own iCloud Drive. It's off unless you switch it on.

Your administrator password

Some Homebrew steps need administrator rights. When that happens Brewlight shows a password prompt and hands what you type directly to sudo. It isn't saved, logged or sent anywhere, and the prompt closes on its own after two minutes.

This website

This site is hosted on GitHub Pages, which, like any web host, may log your IP address. Fonts load from Google Fonts, and the star count comes from GitHub's public API. The site sets no cookies and runs no analytics. The palette demo on the home page runs entirely in your browser.

Changes

If what Brewlight collects ever changes, this page will change first, with a new date at the top. Brewlight is open source, so you can always check the code yourself.
