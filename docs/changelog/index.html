Release notes

Every pour.

Every Brewlight release, newest first. The same notes are on the GitHub releases page.

1.3.0

Latest 25 November 2026
  • Live install status. While Homebrew installs or upgrades something, Brewlight now says what it is doing and which package it is doing it to: Downloading, Installing, Upgrading or Removing.
  • The status shows in the Activity panel, the sidebar, the package list, the package page and the Updates list, not only in the log.
  • Homebrew's "Fetching downloads" and "Pouring" steps are shown as Downloading and Installing, the words people use.
  • Download progress is shown as an indeterminate bar when Homebrew does not report a percentage, instead of an empty bar that looks stuck.

1.2.0

11 November 2026
  • Casks that update themselves are included in the update check by default, so nothing that brew upgrade --greedy would upgrade is missed. The toggle still lets you hide them.
  • New Needs attention section on Updates for packages no longer in Homebrew, which make brew upgrade fail, and apps deleted by hand while brew still tracks them. Each has a one-click Uninstall.
  • Uninstall and Remove Completely now render red in menus.
  • About links point to this website.

1.1.0

8 November 2026
  • A failed uninstall no longer deletes the checked leftover files. They are removed only when the uninstall itself succeeded.
  • The background update check runs brew update through Brewlight's own operation queue, so it cannot race your installs or upgrades.
  • Clear All Caches (Settings, Privacy) clears the cache contents instead of deleting the folder out from under running features.
  • Package downloads cached as plain files by older Homebrew layouts now show up in the detail view, sizes and cleanup, and can be cleared.
  • Homebrew found at a path containing spaces (Settings, Homebrew override) is detected correctly.
  • Package icons cached more than a month ago are fetched again, so the icon cache stops growing forever.
  • Packages that leave Homebrew's catalog drop out of Brewlight's own package history.

0.1.0

3 November 2026
  • First release: Spotlight, but for brew. A fast, native Mac app for everything you do with Homebrew.
  • Press ⌘K to search all 16,000 formulae and apps as you type, with filters like is:outdated, type:cask and cat:browsers.
  • Discover what the community is installing, with real install counts.
  • Upgrade everything at once or one by one. Pinned packages and skipped versions stay put.
  • Remove apps completely, leftover files included, to the Trash.
  • Every confirmation shows the exact brew command that will run.
  • Services, taps, cleanup and disk usage, dependency trees, Brewfile import and export, and a full history.
  • In English, Deutsch, Español, Français, 日本語 and 简体中文.
Brewlight is not notarized yet. The first time you open it, macOS blocks it: go to System Settings, Privacy & Security and click Open Anyway.

Install or update

brew install --cask prempoddar/tap/brewlight, then brew upgrade --cask brewlight for later versions. You can also download the latest Brewlight.dmg.

Older builds and their attached notes are in the GitHub releases.
